The Velvet Vault — a top-down stealth heist in three museum rooms. Sneak past
guards and cameras, take each room's prize, reach the exit. Serve `game/` with
any static server, open `index.html`, move with WASD or arrows, sneak with
Shift, place gadgets with keys 1–3 and the mouse.
