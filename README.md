Solmar Bay — a sun-soaked open-world crime game for the [gta6-01 bounty](https://make.fun/bounty/gta6-01): drive and walk a living city, steal cars, outrun the SBPD, and run nine story missions for fixer Vera Solano. Serve `game/` with any static server and open `index.html`; WASD to drive or walk, E to get in a car, mouse to aim, click to shoot.
